What's New

  • A new Settings → Experimental pane collects features that are still settling in, each off by default: smooth trackpad scrolling through scrollback, a cursor that glides between positions, and a fading cursor trail. (#394)
  • Experimental also gains Animate splits, which slides a new pane in from its own edge of the split while its neighbor makes room, and slides a closing pane back out. (#396)
  • Quick terminal panes now survive a quit: their sessions persist and the panel reopens onto them after a relaunch. (#392)

Fixes

  • Quitting with a command running in the quick terminal no longer asks for confirmation. (#392)
  • Trackpad and wheel scrolling now follow Ghostty's own conversion, so mouse-scroll-multiplier tunes Macterm exactly as it tunes Ghostty. (#393)
  • A project's layout file now takes effect only through Apply Layout, instead of being applied silently the first time the project is opened. (#391)

Notes

  • Scroll speed, New tab directory, New split directory and Allow Shortcuts to control Macterm have been removed from Settings. Macterm now reads mouse-scroll-multiplier, tab-inherit-working-directory, split-inherit-working-directory and macos-shortcuts from your Ghostty config, and any value you had set in Settings is dropped.
  • Mouse wheel scrollback now moves three rows per notch, Ghostty's default. Set mouse-scroll-multiplier = discrete:1 for the previous one-row feel.
