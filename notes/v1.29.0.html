What's New

  • Smooth scrolling and split animations are on by default, in a new Settings → Appearance → Animations pane that replaces Experimental. Dragging the scrollbar now scrolls between rows and reaches the last lines, and closing a pane in the middle of a row or column merges its dividers instead of dragging one across a neighbour. (#408)

Fixes

  • The smooth cursor draws with hard edges instead of a one-pixel halo, so it is as crisp at rest as the native cursor. (#400)
  • Closing a tab whose only pane mirrors a session another tab still holds no longer warns that it will end a running program, and the tab close command and Close Tab shortcut refuse in the same cases. (#402)
  • A pane squeezed to a few columns, by a window shrunk to the sidebar's width or a layout passing through a tiny size, keeps its content instead of coming back blank. (#409)
